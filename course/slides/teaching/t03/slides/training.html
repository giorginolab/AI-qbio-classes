Training · the loop

Training is repeated small corrections that reduce a loss

Show the network a batch of 64 sequences, compute the cross-entropy loss, −log of the probability given to the true class, and let the optimiser (Adam) nudge every weight downhill. One pass over the training set is an epoch.

Keep three sets apart: training to fit the weights, validation to choose settings such as the number of epochs, test touched once at the end.

The gradient of the loss with respect to every weight is computed by backpropagation (backward() in PyTorch); for an RNN this runs back through all positions, “backpropagation through time”. In the notebook the test set is watched each epoch for teaching purposes only; say this explicitly so students do not copy the habit.
