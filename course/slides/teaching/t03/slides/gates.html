Model · gated recurrent unit

Gates let the network decide what to keep and what to forget

A plain RNN multiplies the hidden state by the same matrix at every step. Over many steps the training signal (the gradient) shrinks or explodes, so long-range information is hard to learn.

A GRU adds two gates, numbers between 0 and 1 computed from the input and the state. The update gate sets how much of the old state to keep; the reset gate sets how much of the past to use when proposing new content.

With the update gate near “keep”, information can pass unchanged across many residues.

LSTMs (used by TargetP 2.0) follow the same principle with three gates and a separate memory cell. GRUs are a lighter variant and usually perform similarly. The gates are learned from data like all other weights; nobody tells the network which residues to remember.
