Three ideas to take home from this session

Order is information

In a biological sequence, where a residue sits can matter as much as which residue it is.

Match model to data

A recurrent network reads a sequence in order, so it can use information that a composition model cannot see.

Test what it uses

Controls and interpretation show whether a model learned the biology or something else.

Frame the whole session with these three points and come back to them in the summary. The worked example is a mini version of TargetP: predicting from the first 50 residues whether a protein carries a signal peptide, a mitochondrial transit peptide, or neither.
