At each position, h_t = f(x_t, h_t−1): the new state mixes the current residue x_t with everything read so far. After residue 50, a linear layer turns h_50 into three class scores.

The same f, with the same weights, is applied at every position. The network can detect a pattern wherever it occurs, and its size does not grow with sequence length.

The arrows carry the hidden state, here a vector of 32 numbers. In a plain RNN, f is h_t = tanh(W·x_t + U·h_t−1 + b): W and U are learned matrices shared by all positions. Weight sharing is the same idea as in convolutional networks, applied along time instead of across space. Parameter count of our model: 3 · (32 · (20 + 32) + 2 · 32) = 5184 for the GRU plus 32 · 3 + 3 = 99 for the linear layer, 5283 in total, as printed in the notebook.
