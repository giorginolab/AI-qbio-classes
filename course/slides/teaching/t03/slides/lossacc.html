The loss sees overfitting before the accuracy does

For 128 hidden units the test loss rises after epoch 10 (0.16 → 0.23) while test accuracy barely moves. The network gets the same proteins right but becomes over-confident on the ones it gets wrong, and −log p punishes that hard.

Accuracy only asks whether the top class is right; the loss also asks how confident the network was. That is why early stopping usually watches the validation loss. Over-confident probabilities are a problem in their own right whenever predictions are used as probabilities, for instance to rank candidates for an experiment.
