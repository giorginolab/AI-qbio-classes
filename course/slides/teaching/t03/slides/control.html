Method · controls

To learn what a model uses, take that thing away and see what breaks

Shuffle the residues within each sequence. Composition is unchanged; order is destroyed. If the network used only composition, its accuracy would not change.

This is an ablation or control experiment, the same logic as a knockout in genetics: remove one ingredient, keep everything else fixed, measure the effect.

Other controls of the same family: shuffle the labels (the model should drop to chance; anything above reveals leakage), remove one input feature at a time, or train on a deliberately simpler representation. A high score alone never says what the model learned.
