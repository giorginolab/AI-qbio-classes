The general idea

Split the data the way the model will meet new cases

If samples are related (families, species, patients, molecules with the same scaffold), group them so that the test set contains only groups the model has not seen. Then ask what every stage of the pipeline has seen, including pretrained parts. The honest score is the one that matches the claim you want to make.

This idea recurs across the course: grouped CV in t02, orders held out in s02.
