The general idea

Pretraining turns unlabelled data into a reusable representation

Labels are scarce and expensive; sequences are abundant. A model trained on a self-supervised task over millions of sequences learns regularities that many downstream tasks can use, each with a few labelled examples and a simple model. The same recipe underlies language models for text, DNA and single-cell data.

Emphasise that ESM-2 never saw an EC number. The knowledge it has about function is a by-product of modelling sequences.
