Protein language models

Learn from sequences alone by guessing hidden residues

ESM-2 was trained on about 65 million protein sequences, with no annotation at all: hide some residues, predict them from the rest.

The network outputs a probability for each of the 20 amino acids at the hidden position, using context on both sides.

To play this game well across millions of proteins, it has to pick up what constrains sequences: families, folds, contacts, binding sites. None of this is taught explicitly.

This is the same objective as masked language models for text, which learn grammar and meaning from guessing missing words. The example sequence is illustrative. Pretraining = learning a general representation from a large unlabelled dataset; it is self-supervised because the labels (the hidden residues) come from the data itself.
