Letters are protein families. In scikit-learn the grouped split is StratifiedGroupKFold with the family as group; stratified keeps the six classes balanced in each fold. Ask: which split matches the question you want to answer? To annotate a new protein from a known family, the random split is fine; to predict function for a new family, only the grouped split is honest.
