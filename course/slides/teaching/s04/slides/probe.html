Linear probes

Keep the classifier simple to measure the representation

A logistic regression is a linear model: the classification counterpart of fitting a straight line. It can only draw flat boundaries between classes.

If such a weak model succeeds, the information was already organised in the input. This setup is called a linear probe.

Training a small model on top of a large pretrained one is transfer learning: the expensive learning is reused for a new task with few labels.

Why not a random forest or an MLP? A flexible classifier could build its own features from composition and blur the comparison. Keeping it linear isolates the effect of the representation.
