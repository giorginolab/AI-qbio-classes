Networks learn the coarse trend first, the noise last

A toy dose-response curve with 20 noisy points. Epoch 10: nearly a straight line. Around 170: the S shape. By 3000: bends that follow single points. Test error is lowest near epoch 380, close to the noise level, then rises while training error drops below the noise.

Exercise A.3. Test MSE best 0.048 at epoch about 380 (noise level 0.04), then 0.061; training error 0.007. With alpha = 0.1 the curve stays smooth and test error keeps falling (0.049). With alpha = 1, too stiff (about 0.09): underfitting. width = 8 or n_train = 200 both help; more data is the more reliable cure. Different seeds give different curves: averaging several networks (an ensemble) reduces this variance.
