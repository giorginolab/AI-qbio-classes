The general idea

Fit the signal, not the sample

A training error below the noise level means the model is memorising. Four standard cures, all limiting what the model can learn from one particular sample: more data, a smaller model, a penalty on large weights, and stopping early. Judge each choice on data the model has not seen.

Ensembles (averaging several networks trained from different random starts) are a fifth cure, for variance. All of these apply to any flexible model, not only neural networks.
