Confusion matrix

Which classes get confused with which

Rows are true classes, columns predictions; the diagonal is what the model gets right. No class is easy: recall 0.30–0.45 each, errors spread over all columns. Oxidoreductases are hardest.

Oxidoreductases are a huge and chemically diverse class (NAD-, FAD-, heme-, metal-dependent enzymes in many unrelated folds) with no common composition. EC classes describe the chemistry of the reaction, which evolution has invented many times in unrelated folds, so composition is a weak proxy for it. Recall of a class = correct predictions of that class / members of that class.
