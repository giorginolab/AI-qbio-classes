The bootstrap

Imitate “another sample” by resampling the one we have

Data

422 species

Resample

draw 422 with replacement

Refit

record the slope

Repeat

2000 times; read the spread

Some species appear twice in a resample, others not at all. The middle 95% of the refitted slopes is a 95% confidence interval.

The bootstrap treats the sample as a stand-in for the population. It works for any statistic (a median, a ratio, a classifier accuracy) without a formula. It assumes the species are independent draws, which is only approximately true: related species are similar, a point that returns with grouped cross-validation in session 2.
