Categorical variables

A group label can be part of the model

A categorical variable takes a few named values, such as the class of an animal. In a linear model it can give each group its own intercept while the slope stays shared.

On a log scale a different intercept means a constant factor: the same law, shifted up or down. One extra variable can explain a large part of the remaining variation.

Technically this is done with indicator (one-hot) columns: one 0/1 column per class, minus a reference class. The same encoding reappears for amino acids in session 3.
