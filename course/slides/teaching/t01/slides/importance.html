Permutation importance: how much worse is the model without this input?

Shuffle one descriptor in the test set and measure the drop in R². MLOGP (0.43) and SM1_Dz (0.24) matter most, as the correlations suggested. It describes this model, not nature: correlated inputs share importance, and important does not mean causal.

Works for any model, including black boxes. If two descriptors carried the same information, shuffling one would cost little because the model could use the other.
