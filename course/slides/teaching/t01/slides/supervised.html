Supervised regression

A model is a function from inputs to a target, chosen to make errors small

Inputs (features) x: the six descriptors. Target y: LC50. A model f gives a prediction ŷ = f(x); fitting chooses the parameters of f that make the errors y − ŷ small on the training data.

The real goal is generalisation: small errors on chemicals the model has not seen. So we hold data out as a test set and never use it for fitting.

In the notebook 227 chemicals (25%) are held out and 681 used for training. Regression: numeric target. Classification: categories (sessions 2 and 3).
