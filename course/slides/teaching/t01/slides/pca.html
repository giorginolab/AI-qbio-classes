Unsupervised learning

PCA draws a map of many variables in two dimensions

Principal component analysis finds the directions along which the data vary most. Projecting on the first two gives a 2D map where nearby points have similar descriptors.

It never sees the target: we colour by LC50 afterwards. Variables are first standardised (mean 0, standard deviation 1), or the one with the largest units dominates.

The same tool maps expression profiles, sequences or species traits.

Each component is a weighted sum of standardised descriptors; the weights are the loadings. Variance explained says how much of the spread the map shows.
