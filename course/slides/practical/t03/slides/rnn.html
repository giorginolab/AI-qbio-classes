Part 5 · a recurrent neural network

Read one residue at a time, and keep a hidden state that summarises what has been read

ht = f ( xt , ht−1 )

The same f, with the same weights, at every one of the 50 positions. After the last residue a linear layer turns h50 into 3 scores: other, SP, mTP.

A GRU adds gates that decide what to remember and what to forget. GRU(20 → 32) + Linear(32 → 3): 5283 parameters.

Training: batches of 64 sequences, cross-entropy loss (how wrong the class probabilities are), Adam nudges every weight to reduce it. One pass over the training set is an epoch. We watch test accuracy here for teaching only; in a real project choose epochs on a separate validation set and touch the test set once at the end.
