Two ways to turn a protein into numbers

21

Composition

Fraction of each of the 20 amino acids, plus length. No learning involved. Each column has a meaning.

320

ESM-2 embedding

A network trained on about 65 million sequences to guess hidden residues. One vector per residue in context, averaged. Never shown an enzyme class.

We use the smallest ESM-2, 8 million parameters. Guessing hidden residues from context is like a language model guessing a missing word. The embedding columns have no meaning that we know of.
