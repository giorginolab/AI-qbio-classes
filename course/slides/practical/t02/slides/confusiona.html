No class is easy. Oxidoreductases are the hardest.

Recall is about 0.30 – 0.45 for each class and errors spread over all columns.

Oxidoreductases are a huge, chemically diverse class (NAD-, FAD-, heme-, metal-dependent enzymes in many unrelated folds) with no common composition. EC classes describe the chemistry of the reaction, which evolution invented many times in unrelated folds, so composition is a weak proxy.
